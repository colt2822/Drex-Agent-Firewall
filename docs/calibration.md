# Drex Agent Firewall: Calibration & Outcome Evaluation

## 1. Overview

A probabilistic security layer is only as reliable as its mathematical calibration. If an engine outputs an 85% probability of risk, approximately 85% of such actions should empirically warrant blocking or human escalation.

**Drex Agent Firewall** tracks:
1. **Predicted Probabilities**: Full 8-dimensional probability distributions generated by Drex or local providers.
2. **Deterministic Enforcement Decisions**: ALLOW, ALLOW_WITH_CONSTRAINTS, ESCALATE, ABSTAIN, BLOCK.
3. **Empirical Outcomes**: SUCCESS, FAILURE, ERROR, BLOCKED.
4. **Outcome Feedback**: Asynchronous recording of downstream runtime outcomes via `/v1/actions/{id}/outcome`.

## 3. Latency & Overhead Benchmark Profiles

Latency was measured across 3 distinct operational modes (200 iterations for local and replay, bounded requests for live API):

```
Local Policy Only:   [0.135ms P50] ━━━━━━━━━━━━━━━━━━━━━━━━━ (7,120 ops/sec)
Full Replay Stack:   [0.359ms P50] ━━━━━━━━━━━━━━━━━━━━━━━━━ (1,676 ops/sec)
Live Drex API (WAN): [262.66ms P50] ━━━━━━━━━━━━━━━━━━━━━━━━
```

| Component | P50 (ms) | P95 (ms) | P99 (ms) | Mean (ms) | Throughput (ops/sec) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **1. Local Deterministic Policy** | **0.135** | **0.181** | **0.372** | **0.140** | **7,120.3** |
| **2. Full Replay Firewall (with SQLite WAL)** | **0.359** | **0.595** | **6.621** | **0.596** | **1,676.5** |
| **3. Live Drex API (`drex-v1.5` over HTTPS)** | **262.661** | **276.061** | **276.061** | **259.435** | **N/A (WAN bound)** |

### Overhead Analysis
- **Local Invariant Cost**: Running normalization, secret redaction, and deterministic hard rules adds approximately **0.14 ms** of overhead.
- **SQLite WAL Write Cost**: Storing complete action envelopes, distributions, and execution results in SQLite WAL mode adds **~0.22 ms**.
- **Live Drex API Overhead**: WAN latency to `drex.nace.ai` is approximately **260 ms**, suitable for high-risk operations requiring remote model judgment.
